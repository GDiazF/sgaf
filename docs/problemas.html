Problemas frecuentes

Soluciones rápidas. Si persiste, revisa logs con docker compose logs -f backend.

Login: error 400 Bad Request

El servidor no reconoce la URL del navegador.

cd ~/sgaf
./scripts/sync_env_network.sh
docker compose up -d backend

Actualicé pero no veo cambios en pantalla

docker compose up -d --build frontend

O deploy completo sin --quick (ver Actualizar).

Git push rechazado

git pull origin reingenieria
git push origin reingenieria

No aparece menú Bandeja de firmas

Revisa Firma y permisos y vuelve a iniciar sesión.

firma-dep no responde

docker compose logs -f firma-dep
docker compose up -d --build firma-dep

Verifica API_ALLOW_PRIVATE_NETWORKS=true y que API_CLIENT_KEYS coincide con FIRMA_DEP_API_KEY.

Cambiar contraseña admin

docker exec -it sgaf_backend_prod python manage.py changepassword admin
