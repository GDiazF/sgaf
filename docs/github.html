Subir cambios a GitHub

En tu PC Windows, después de probar que todo funciona localmente.

Flujo completo Probar en PC → git push → en el servidor: Actualizar sistema
  1. Ver cambios pendientes 
    cd "C:\...\SGAF_CC"
git status
  2. Si modificaste la base de datos (solo en tu PC) 
    cd backend
python manage.py makemigrations
python manage.py migrate
    Incluye archivos nuevos en migrations/ en el commit.
  3. Guardar cambios 
    git add .
git commit -m "Describe el cambio en una frase"
  4. Subir a GitHub 
    git push origin reingenieria
