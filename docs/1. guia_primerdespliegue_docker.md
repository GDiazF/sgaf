# Guía de Despliegue y Orquestación Docker - SGAF

Despliegue automatizado con scripts en `scripts/`. No hace falta editar IP/hostname manualmente en cada variable de red.

## 1. Descarga del código

```bash
git clone -b reingenieria https://github.com/GDiazF/sgaf.git
cd sgaf
chmod +x scripts/*.sh scripts/lib/*.sh
```

## 2. Configuración automática

```bash
./scripts/setup_env.sh
```

Esto crea `.env` (si no existe), detecta IP/hostname del servidor y configura `ALLOWED_HOSTS`, CORS, CSRF y URLs públicas.

### Secretos que debes editar manualmente (una vez)

```bash
nano .env
```

| Variable | Descripción |
|----------|-------------|
| `SECRET_KEY` | Clave Django (generar una larga y aleatoria) |
| `DB_PASSWORD` | Contraseña PostgreSQL |
| `FIRMA_GOB_API_TOKEN_KEY` | Token Key de la RA |
| `FIRMA_GOB_SECRET` | Secret de la RA |
| `FIRMA_DEP_API_KEY` / `API_CLIENT_KEYS` | Mismo valor: `sgaf-backend:tu_clave` |
| SMTP | `EMAIL_HOST_PASSWORD`, etc. |

### Puerto del frontend

Por defecto `FRONTEND_PORT=80` en `.env.example`. Si usas otro puerto:

```env
FRONTEND_PORT=8080
```

Luego: `./scripts/sync_env_network.sh`

## 3. Despliegue

```bash
./scripts/deploy.sh
```

Incluye build, migrate y collectstatic. Al final muestra la URL de login.

Servicios Docker: `db`, `backend`, `frontend`, `firma-dep` (sidecar firma digital, puerto 4010 interno).

Permisos de firma digital y variables `FIRMA_*` / `API_CLIENT_KEYS`: ver sección 4 de [2.2 guia_actualizacion_sistema.md](./2.2%20guia_actualizacion_sistema.md).

## 4. Actualizaciones posteriores

```bash
git pull origin reingenieria
./scripts/deploy.sh --backup
```

## 5. Restaurar backup SQL

```bash
cat ~/backup.sql | docker exec -i sgaf_db_prod psql -U sgaf_user -d sgaf_db
```

## 6. Mantenimiento

| Comando | Acción |
|---------|--------|
| `docker compose ps` | Estado de contenedores |
| `docker compose logs -f backend` | Logs del backend |
| `./scripts/sync_env_network.sh` | Re-sincronizar red tras cambiar IP/hostname |
| `docker compose restart` | Reinicio rápido |

## 7. Automatización Cron

```bash
chmod +x scripts/*.sh
crontab -e
```

```cron
30 8 * * * /home/svtest/sgaf/scripts/enviar_recordatorios_diarios.sh
0 * * * * /home/svtest/sgaf/scripts/cleanup_expired_data.sh
0 9,18 * * * /home/svtest/sgaf/scripts/respaldo_automatico_sgaf.sh >> /home/svtest/backup_log.txt 2>&1
```

Ajusta rutas según tu usuario y carpeta del proyecto.
