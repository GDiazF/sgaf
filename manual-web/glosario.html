Glosario

Palabras que aparecen en las guías, explicadas en simple.

PalabraSignificado
~/sgafCarpeta del proyecto en el servidor Ubuntu
.envArchivo de configuración y contraseñas (nunca en Git)
SSHConexión remota al servidor desde tu PC
DockerSistema que ejecuta SGAF en «contenedores» aislados
ContenedorProceso empaquetado: frontend, backend, base de datos, firma-dep
git pullBajar últimos cambios desde GitHub al servidor
git pushSubir cambios desde tu PC a GitHub
migrateActualizar estructura de la base de datos (automático en deploy)
firma-depServicio interno que conecta SGAF con FirmaGob
OTPCódigo 6 dígitos del certificado FirmaGob (no es el MFA de login SGAF)
RCRecepción conforme (documento de pagos/servicios)
media/Carpeta de archivos subidos (fotos, PDFs)
cronProgramador de tareas automáticas en Linux (respaldos)
