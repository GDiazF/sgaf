Desarrollo local en tu PC

Sin Docker. Abre SGAF en http://localhost:5173

Terminal 1 — Backend

cd backend
python -m venv venv
.\venv\Scripts\activate
pip install -r requirements.txt
python manage.py migrate
python manage.py runserver 8000

Crea backend/.env con DEBUG=True, CORS para localhost:5173 y FIRMA_DEP_URL=http://127.0.0.1:4010/api/v1.

Terminal 2 — Frontend

cd frontend
npm install
npm run dev

En frontend/.env: VITE_API_URL=http://localhost:8000/api

Terminal 3 — Firma (opcional)

cd services\firma-dep
npm install
copy .env.example .env
npm run start:dev

Token/Secret FirmaGob van en services/firma-dep/.env.
