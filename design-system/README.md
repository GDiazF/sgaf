# @slep/ui — Design System SLEP Iquique

Paquete React + Tailwind que porta el OpenDesign institucional.

## Desarrollo (playground)

```bash
cd design-system
npm install
npm run dev
```

Abre http://localhost:5174

## Uso desde `frontend/`

```js
import { Button, AppShell, PageHeader } from '@slep/ui'
import '@slep/ui/styles'
```

El alias Vite debe apuntar a esta carpeta (ver `frontend/vite.config.js`).
